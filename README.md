## The Challenge

Starting **1 September 2026**, I am committing to **365 consecutive days of coding**.

No excuses.

No skipped days.

No "I'll do it tomorrow."

For an entire year, I will build, experiment, learn, solve problems and improve my programming skills.

### And there's a catch...

**Everything will be coded on my iPhone 12.**

That means this challenge isn't about having the best hardware.

It's about proving that **consistency and creativity matter more than equipment.**

# 📱 Coded Entirely on an iPhone

One of the main rules of this challenge is simple:

> **The coding happens on my iPhone 12.**

No powerful desktop setup.

No dedicated development machine.

Just an iPhone, an internet connection, and a lot of determination.

This makes the challenge slightly different from the usual coding challenge.

I'm not trying to prove that I can code with the perfect setup.

I'm trying to prove that **I can code anywhere.**

---


# 📈 The Rule

The most important rule is:

## **I MUST CODE EVERY DAY.**

It doesn't have to be a huge project.

It doesn't have to be thousands of lines.

It doesn't have to be impressive.

Because this challenge is ultimately about one thing:

# **Consistency.**

# 🌟 Why I'm Doing This

Coding is something I genuinely enjoy.

But knowing how to code isn't enough.

The real skill is being able to:

> **show up consistently, solve problems, build things and keep learning.**

365 days gives me a full year to develop that habit.

By the end of this challenge, I want to look back at Day 001 and see just how much I've changed.
